# 大健康产品分析器

膳食补充剂 / 功能性食品 / 大健康品类的结构化分析 Claude Code Skill。

按「市场端 → 产品端 → 竞争端」三层框架逐项评估，辅助产品经理判断一个品类或成分值不值得做。

## 功能

- **快速扫描**：输入一个品类/成分，按框架逐项输出评估和最终建议
- **深度对比**：输入 2-3 个品类/成分，输出横向对比表，给出优先级推荐
- **可选数据补充**：用户确认后搜索公开数据（政策公告、搜索趋势、PubMed文献等）
- **边界声明**：每次分析首屏告知能力边界，不承诺拿不到的闭源数据

## 分析框架

```
市场端                    产品端                    竞争端
├─ 品类心智教育程度       ├─ 成分合规性             ├─ 竞争格局
├─ 品类规模 & 天花板      ├─ 原料成本 & 供应稳定性   ├─ 自身优势匹配
├─ 增长动因拆解           ├─ 科学依据强度            └─ 时机判断
├─ 复购属性               └─ 宣称空间
├─ 认知链路长度
└─ 消费者决策路径
```

核心逻辑：**市场有机会 + 产品能做 + 竞争可胜 → 值得做**

## 使用方法

### 1. 安装

将 `SKILL.md` 放入 Claude Code 的 skills 目录：

```bash
mkdir -p ~/.claude/skills/大健康产品分析器
# 将 SKILL.md 放入该目录
```

### 2. 调用

在 Claude Code 中直接输入：

```
/大健康产品分析器
```

按引导选择模式：
- 输入 `1` 进入快速扫描（单品类）
- 输入 `2` 进入深度对比（多品类）

## 输出示例

快速扫描模式下，按框架逐项评分，输出类似：

```
┌─────────────────────────────────────────┐
│  【市场端】● 正面  │ 【产品端】○ 待定    │
│  【竞争端】● 正面  │ 建议：✅ 值得做     │
└─────────────────────────────────────────┘
```

## 局限性

- 不提供精确 GMV / 销量 / 市占率（平台数据封闭）
- 不承诺实时原料定价（仅做相对判断）
- 输出为分析参考，不替代内部商业决策
- 建议将分析结果作为起点，结合自身供应链、渠道等内部信息做最终判断
